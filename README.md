# ☁️ Cloud Storage Web Application

A clean, multi-tenant cloud storage web application built with **FastAPI**, **SQLAlchemy**, and **Jinja2**. Designed with a streamlined, folder-first architecture for seamless file and media management.

---

## 🚀 Features

- **Multi-Tenant User System:** Pre-configured generic accounts with secure SHA-256 password hashing.
- **Folder-First Organization:** Clean dashboard layout focusing purely on custom folder creation (e.g., *Wedding Photos*, *Documents*) and file management.
- **Media Previews:** Direct browser preview for images (`.png`, `.jpg`, `.jpeg`), documents, and other file types without mandatory downloading.
- **Fast & Lightweight:** Powered by FastAPI and SQLite for high-speed local or cloud execution.

---

## 🛠️ Tech Stack

- **Backend:** Python, FastAPI, Uvicorn, SQLAlchemy
- **Templating:** Jinja2
- **Database:** SQLite
- **File Handling:** Python Multipart / OS file management
